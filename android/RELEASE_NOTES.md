# يومي LifeOS — Android APK v1.2.0 (التطبيق الأصلي + ويدجتس الشاشة الرئيسية)

هذا تحديث لتطبيق **يومي LifeOS** نفسه (`com.yawmilife.app`)، وليس تطبيقًا إضافيًا.

## الويدجتس الأصلية
من شاشة هاتف Android الرئيسية، اضغط مطولًا على مساحة فارغة → الويدجتس → **يومي LifeOS**.

يمكن اختيار ستة ويدجتس:
- لوحة اليوم: نسبة الإنجاز، المهام والعادات.
- الإنتاجية: المنجز من المهام والعادات.
- التخطيط: الأهداف ونسبة إنجاز اليوم.
- القراءة والقرآن: الكتب، صفحات القراءة، وXP.
- الصحة والروتين: استهلاك المياه وأيام النشاط.
- شؤون حياتي: المستوى، XP، وأيام النشاط.

لكل ويدجت زر تحديث، وأزرار اختصار لأقسام التطبيق. التحديث الدوري يخضع لقيود Android وقد يتأخر أثناء توفير البطارية.

## ربط حساب يومي
بعد تثبيت **التحديث الرسمي الموقّع بنفس شهادة النسخة v1.0.0**، افتح يومي وسجّل الدخول.
من الصفحة الرئيسية افتح «ويدجتس شاشة الهاتف»، واضغط «ربط ويدجتس الهاتف» ثم «ربط ويدجتس تطبيق يومي الأصلي». 

تُرسل ملخصات رقمية فقط عبر Supabase بحسابك الخاص ورمز قراءة عشوائي قابل للإلغاء، ولا تُرسل أسماء المهام أو الملاحظات أو البيانات المالية الحساسة للويدجتس. يوجد خيار فصل جميع الأجهزة.

## شرط مهم لتحديث APK الحالي
**يُمنع استخدام مفتاح جديد لتحديث `com.yawmilife.app`.** يرفض GitHub Actions إصدار ملف تحديث عام إن لم يُتحقق من بصمة الشهادة الأصلية:

`C9:41:1A:EB:C3:83:EC:82:00:17:7D:6B:C2:AF:79:56:02:90:C4:F0:A1:03:5B:45:BA:AD:CC:F1:AF:B6:F3:D8`

يتوفر أرشيف توقيع **مشفّر بمفتاح عام** ضمن تشغيل GitHub Actions الأصلي:
https://github.com/yawmi-life/home/actions/runs/42038925659

يمكن لصاحب التطبيق إضافة أحد الخيارين في مستودع GitHub من
Settings → Secrets and variables → Actions → New repository secret:

1. `YAWMI_ANDROID_KEYSTORE_B64` بالإضافة إلى `YAWMI_ANDROID_KEYSTORE_PASSWORD`، إن كان يحتفظ بمفتاح التوقيع الأصلي.
2. **أو** `YAWMI_SIGNING_RECOVERY_PRIVATE_KEY_B64`: محتوى ملف المفتاح الخاص المقابل لشهادة `android/signing-backup-public-cert.pem` بعد تحويله إلى Base64 في جهاز آمن. يسترجع مسار البناء الأرشيف المشفّر ويحاول فكّه داخل GitHub Actions مؤقتًا، ثم يفحص بصمة شهادة التوقيع قبل التوزيع.

**لا تنشر أو ترسل المفاتيح أو كلمات المرور في دردشة أو مستودع عام.** إذا ضاع مفتاح التوقيع الأصلي ومفتاح فك التشفير معًا، لا يمكن إنشاء تحديث متوافق بنفس هوية تطبيق Android المثبت.

## حالة التحديث
يمكن بناء نسخة QA لاختبار الكود، لكن هذه النسخة ليست تحديثًا موقّعًا بالمفتاح الأصلي ولا ينبغي تثبيتها مكان تطبيقك الحالي. لا يرفع نظام الإصدار تحديثًا عامًا إلا بعد اجتياز فحص التوقيع.

## متطلبات إضافية
لا تزال عملية Digital Asset Links لجذر `https://yawmi-life.github.io/.well-known/assetlinks.json` مطلوبة لإخفاء شريط Chrome في تجربة Trusted Web Activity بالكامل، لكنها ليست شرطًا لظهور الويدجتس الأصلية في قائمة Android.
