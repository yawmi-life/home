# YAWMI LifeOS V36 — ملخص التنفيذ والتحقق

**الحالة:** منجز للموقع، مع متابعة إصدار Android الموقّع.

## وظائف تم تنفيذها داخل التطبيق
- لوحة «يومك ببساطة» تعرض 3 مهام أولى، العادات غير المكتملة، موعد التقويم الأقرب، تقدم القراءة، وحالة المزامنة. لا يتم منح XP لمجرد عرض اللوحة.
- زر (+) ثابت لإضافة مهمة أو تذكير أو ملاحظة بسرعة، مع تحليل عبارة عربية مثل «فكرني أراجع بكرة الساعة 8 مساء» وعرض التاريخ والوقت والنوع للمراجعة قبل الحفظ. الإملاء الصوتي متاح فقط حيث يدعمه المتصفح، ويتطلب إذنًا.
- «يوم خفيف» يخفض أولويات العرض إلى عنصر واحد، ولا يوقف العادات أو يمسح المهام أو يغير XP أو سجلات الإنجاز.
- أيام الراحة لكل عادة، مع رفض تغيير أيام الماضي أو إخفاء تقدم مسجل. ربط «عادة بعد أخرى» تنسيق فقط ولا يسجّل إنجازًا تلقائيًا، ويمنع حلقات الربط الدائرية.
- ترشيحات مواضيع كتب من مكتبة المستخدم، مع البحث الحقيقي في الفهرس، وليس ضمانًا لوجود كتاب محدد. تبقى إضافة الكتب غير المفهرسة يدويًا متاحة.
- اقتراح أسبوعي لمهمة صغيرة يتطلب تأكيدًا، ولا يمنح XP إلا عند الإنجاز الحقيقي.
- تصدير نسخة JSON محلية من الحساب، مع تحذير بأنها تحتوي بيانات خاصة، وإمكانية استعادة نسخة **من الحساب نفسه فقط** بعد تأكيد واضح واستيفاء شروط المزامنة. الاستعادة تغيّر الحالة كاملة، لذا يلزم حفظ نسخة قبل استخدامها.
- حالة مزامنة ظاهرة، تميّز بين العمل بدون إنترنت والمزامنة الجارية وتعارض البيانات. تحسين عرض المناسبات السنوية المتكررة في ملخص اليوم بدون تغيير سجلاتها الأصلية.
- لا أقسام جديدة في القائمة الجانبية.

## إصدار Android وتحديثات APK
- المشروع يحتوي على ويدجت Android **اختصارات فقط** لفتح المهام والعادات والتقويم. لا يعرض بيانات مستخدم خاصة خارج المتصفح ولا يسجل «تم» في الخلفية دون تفويض.
- تم إنشاء **نسخة Android debug للاختبار**، لكنها **ليست تحديثًا عامًا صالحًا للتثبيت فوق APK الموقّع 1.0.0**.
- التطبيق العام الحالي على GitHub Release ما زال `android-v1.0.0`. لإصدار `android-v1.1.0` بنفس package ID `com.yawmilife.app` يجب إضافة مفتاح توقيع الإصدار 1.0.0 الأصلي إلى GitHub Actions Secrets:
  - `YAWMI_ANDROID_KEYSTORE_B64`: ملف التوقيع الأصلي بترميز base64.
  - `YAWMI_ANDROID_KEYSTORE_PASSWORD`: كلمة مرور المفتاح الأصلي.
- يبني CI الإصدار الجديد فقط عند وجود نفس شهادة التوقيع، ويرفض أي شهادة مختلفة عن البصمة الأصلية:
  `C9:41:1A:EB:C3:83:EC:82:00:17:7D:6B:C2:AF:79:56:02:90:C4:F0:A1:03:5B:45:BA:AD:CC:F1:AF:B6:F3:D8`.
- **لا تضع المفتاح الخاص أو كلمة مروره في GitHub العام أو المحادثات أو ملفات الكود**. استخدم ملف الاستعادة الخاص الذي سبق تسليمه لمالك التطبيق. مفاتيح GitHub Secrets لا يمكن كتابتها من موصل القراءة/التعديل الحالي.
- لتفعيل TWA بملء الشاشة يلزم `https://yawmi-life.github.io/.well-known/assetlinks.json` في **جذر نطاق GitHub Pages**؛ رفعه داخل المستودع `/home` وحده لا يكفي. التوثيق في الجذر لم يُثبت بعد.
- تفعيل Web Push مع التطبيق مغلق يتطلب إشعارات الجهاز وتسجيل اشتراك حقيقي واختبار على Android؛ لا تعتبر نجاح CI إثباتًا لوصول Push فعليًا.

## قيود لا ينبغي إخفاؤها عن المستخدم
- ملخص XP ليس بديلًا عن التحقق الحقيقي من الإنجازات.
- النسخة الاحتياطية JSON ليست مشفرة؛ يجب حفظها محليًا بمكان آمن.
- التصنيف «ذكي» في المساعد الأسبوعي قائم على قواعد محلية، وليس نموذج AI متصلًا.
- تطبيق TWA يعتمد على إصدار الموقع الحي؛ لا يقدم نسخة أصلية Offline مطابقة لكل الوظائف.
- دقة التذكيرات في الخلفية تتأثر بإذن الهاتف، وتوفير الطاقة، والاتصال.
