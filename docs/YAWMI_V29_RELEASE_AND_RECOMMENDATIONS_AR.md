# يومي V29 — ليدر بورد مفتوحة ومعرفات خاصة وواجهة أخف
تاريخ المراجعة: 4 نوفمبر 2026

## التعديلات المنفذة
- كل حساب لديه مستند مسجل يظهر في الليدر بورد الموسمية تلقائيًا، دون زر لإخفائه من المنافسة.
- الترتيب العام لا يحتوي معرّف Supabase أو كود إضافة الأصدقاء؛ يعرض اسم العرض والرتبة والنقاط والمركز وأيام النشاط فقط.
- كود إضافة الأصدقاء يظهر لصاحب الحساب فقط بعد الضغط على «إظهار كودي»، مع زر نسخ ومشاركة.
- طلبات الصداقة الواردة تعرض اسم المرسل فقط. القبول والرفض عن طريق رمز طلب داخلي، لا يعتمد على كود الصداقة.
- صلاحيات SELECT المباشرة إلى جدول friend_requests أُلغيت لتجنب كشف UUIDs الخاصة بالأشخاص.
- حذف بطاقة «سجل الإجراءات والتاريخ» وعناصر التحكم بها من تقرير التقدم في الثيمات الثلاثة، وإزالة عمليات الرسم المتصلة بها.
- لم تُحذف نقاط أو إنجازات أو سجلات محفوظة من حسابات المستخدمين؛ خريطة النشاط والملاحظات والرسوم باقية.
- نسخة الكاش: yawmi-v29-public-shell.

## الاختبارات
- التحقق من إرجاع ثمانية حسابات في leaderboard من Supabase عبر SQL مع صلاحيات authenticated.
- نتائج قائمة المتصدرين لم تتضمن code/user_id مطلقًا، والمعرف متاح داخل profile لصاحب الحساب.
- اختبار إرسال وقبول طلب صداقة في معاملة ROLLBACK دون تغيير علاقة حقيقية، مع عدم عرض كود المرسل.
- فحص عدم امتلاك authenticated صلاحية SELECT على جدول friend_requests.
- فحص JavaScript الخاص بالمنافسة والسكربتات الرئيسية للثيمات الثلاثة بعد إزالة لوحة السجل.

## مقترحات مرتبة للأهمية
1. اختبارات E2E على متصفحات وأجهزة مختلفة، مع Lighthouse وaxe-core لاكتشاف مشكلات PWA والوصول.
2. تثبيت وفتح PWA بدون إنترنت بعد تسجيل الدخول مرة؛ اختبار مزامنة نفس المهمة من جهازين، والتعامل مع التعارض.
3. نقاط منافسة بأحداث خادمية يمكن تدقيقها، بدل الاعتماد فقط على مستند يوميات يمكن للمستخدم تعديله.
4. تحليل فردي لكل عادة مع خريطة حرارية وتذكيرات قابلة للتخصيص؛ استلهام Loop Habit Tracker.
5. احتساب قوة العادة بشكل مرن دون معاقبة المستخدم بشدة عند تفويت يوم أو يومين.
6. تحديات ودية بين الأصدقاء وأوسمة مشتركة، دون عرض كود الإضافة.
7. معاينة النسخ الاحتياطية قبل الاستعادة وواجهة حل تعارض البيانات.
8. عند ازدياد المستخدمين: Pagination + حول مركزي في الترتيب بدل الاكتفاء بأول 50 فقط.
