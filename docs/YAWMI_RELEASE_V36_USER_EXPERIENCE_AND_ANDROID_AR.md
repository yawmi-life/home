## مميزات الموقع المنفذة

**الصفحة الرئيسية:** ملخص «يومك ببساطة» يعرض الأولويات الحقيقية من مهام الحساب وعاداته، الموعد القريب، الكتاب الجاري قراءته، وحالة المزامنة الفعلية. الترتيب حسب الأولوية والساعة، وليس حسب نقاط مفترضة. لا يضيف XP أو يحوّل ضغطة فتح إلى إنجاز.

**الإضافة السريعة:** زر «+» ثابت، يتيح كتابة أمر مثل «فكرني أراجع بكرة الساعة ٨ مساء»، أو إملاءه صوتيًا إن دعمه المتصفح. يتعرف على «اليوم/بكرة/بعد بكرة»، والتاريخ والوقت، ويعرض بيانات المهمة أو التذكير أو الملاحظة ليتأكد منها المستخدم **قبل الحفظ**. لا تُمنح أي نقاط قبل الإنجاز الفعلي. معالجة الصوت قد تمر عبر خدمة المتصفح ولا ينبغي اعتبارها تعرّفًا محليًا مضمونًا.

**يوم خفيف:** تبديل نطاق أولويات ملخص الصفحة الرئيسية بين 3 عناصر وعنصر واحد، من دون حذف أو تعطيل أي مهمة/عادة، ومن دون مساس بتاريخ الإنجاز أو XP. يتذكر اختيار المستخدم لذلك اليوم.

**العادات:** تحديد يوم راحة حالي أو مستقبلي للعادة المختارة وتغييره لاحقًا؛ لا يسمح يوم الراحة بإنشاء إنجاز وهمي، ولا يسمح بوضع راحة على يوم له تقدم مسجل. يمكن تحديد «أعمل العادة بعد عادة أخرى» لعرض تلميح تسلسلي، مع منع علاقات الربط الدائرية. تظل تعديلات التكرار الأساسية موجودة في شاشة تعديل العادة.

**المكتبة:** ترشيحات موضوعات بحث مرتبطة بسجل المكتبة، وإضافة البحث بالرقم الدولي ISBN-10 أو ISBN-13 (بما في ذلك الأرقام العربية) باستخدام فهارس Open Library وGoogle Books. النتائج لا تدعي وجود طبعة عربية ما لم يقدّم المصدر بياناتها. الإضافة اليدوية للكتب غير الموجودة متاحة أصلًا.

**المساعد الأسبوعي:** اقتراح خطوة صغيرة قابلة للإضافة إلى مهام الغد **فقط بعد موافقة المستخدم**. جميع المؤشرات مبنية على البيانات المحلية المحفوظة، ولا يزعم النظام أنها نتائج ذكاء اصطناعي خارجي.

**الحساب والمزامنة:** حالة ظاهرة في ملخص اليوم (جاهزية الحساب، كتابة معلقة، تعارض، رقم مراجعة مؤكدة)، وزر نسخ احتياطي خاص يحتوي بيانات الحساب بصيغة JSON. الاستيراد يتحقق من صاحب الحساب، بنية البيانات، ومفاتيح الملف ويطلب موافقة صريحة قبل الاستبدال. **الكتابة queued في الحساب لا تعني أن الخادم أكدها بالفعل**؛ راجع حالة المزامنة. لا ترسل ملف النسخة الاحتياطية لأحد لأنه قد يضم معلومات مالية ويوميات شخصية.

**تصاميم واجهة يومي:** ATLAS/JOURNAL/QUEST محدثة، ولا يوجد قسم جديد في الشريط الجانبي يسبب ازدحامًا إضافيًا. عمل PWA دون إنترنت في المحتوى المخزن سابقًا كما كان.

## Android Widget والـAPK

- أُضيف مكون أصلي `YawmiShortcutWidget` إلى مشروع Android، يوفّر ثلاثة اختصارات من الشاشة الرئيسية للهاتف: «مهامي»، «عاداتي»، «تقويمي».
- لا يعرض الودجت بيانات مالية أو شخصية، ولا يمنح XP من خارج التطبيق. عرض المهام الخاصة على الودجت وإكمالها يتطلب تطوير قناة حساب أصلية أكثر أمانًا وليس ضمن هذا الإصدار.
- أُضيف رابط `quick=tasks|habits|calendar` لفتح القسم المناسب **بعد تسجيل الدخول**؛ لا تتخطى الروابط حاجز الحساب.
- رُفع رقم Android إلى `versionCode=2`, `versionName=1.1.0` في كود المصدر.
- **تم اجتياز بناء Android debug QA**، لكن APK العام `v1.0.0` ما زال الإصدار الموزع. **لم تُنشأ نسخة عامة موقعة v1.1.0** لأن مخزن GitHub لا يملك بعد بيانات مفتاح التوقيع الأصلي كأسرار Actions. هذه حماية مقصودة لمنع إصدار تحديث لا يستطيع المستخدم تثبيته فوق النسخة الموجودة.
- تم التحقق بصورة محلية من حزمة استعادة التوقيع الخاصة بالمالك، وأن شهادة `yawmi-release.jks` تطابق بصمة الإصدار المنشور `C9:41:1A:EB:C3:83:EC:82:00:17:7D:6B:C2:AF:79:56:02:90:C4:F0:A1:03:5B:45:BA:AD:CC:F1:AF:B6:F3:D8`.
- خط نشر Android الآن يرفض تمامًا إصدار APK جديد بتوقيع مختلف. لبناء نسخة صالحة للتحديث، يلزم إضافة أسرار GitHub التالية في Settings → Secrets and variables → Actions:
  - `YAWMI_ANDROID_KEYSTORE_B64`: النص Base64 لملف keystore الأصلي بعد فك استعادته بصورة خاصة.
  - `YAWMI_ANDROID_KEYSTORE_PASSWORD`: كلمة المرور الأصلية من `signing-password.txt`.
  - ثم تشغيل **YAWMI Android QA and Safe Signed Update** من Actions → Run workflow. عند نجاح التحقق من البصمة سيصدر تحديث `v1.1.0` العام تلقائيًا.
- **ممنوع نشر المفتاح الخام أو Base64 في المستودع العام أو Pull Request أو المحادثات العامة.** احتفظ بنسخ مشفرة في مدير ملفات آمن.

## متطلبات خارجية لا يمكن الادعاء باكتمالها

1. **الملء الكامل للشاشة (TWA):** الرابط `https://yawmi-life.github.io/.well-known/assetlinks.json` لا يقدّم الملف المطلوب حاليًا. يلزم نشر ملف التحقق من حزمة APK بنفس بصمتها في **جذر المضيف** (مثل مستودع GitHub Pages الخاص بالمستخدم `yawmi-life/yawmi-life.github.io` مع `_config.yml` يسمح بملفات `.well-known`) أو استخدام نطاق خاص يديره مالك التطبيق. رفع الملف داخل `/home/.well-known` وحده **لن يصلح التوثيق**.
2. **اختبار Android حقيقي:** بعد اكتمال إصدار جديد يجب اختبار تسجيل الدخول والتثبيت فوق v1.0، والودجت، وDeep Links، والرجوع والأذونات، وإشعارات Web Push فعلية عندما يكون التطبيق مغلقًا.
3. **Web Push:** يوجد خادم Supabase مجدول وخيارات الاشتراك، لكن الاستلام يحتاج تفعيل إذن المستخدم وتسجيل الجهاز. التشغيل الدوري للخادم لا يضمن التسليم للهاتف.
4. **Google Calendar:** يتطلب Google OAuth Web Client ID عام معتمد ومواقع مصرح لها. حاليًا الربط المباشر ليس فعالًا، مع بقاء تصدير ICS وإضافة الموعد إلى Google يدويًا.
5. **المتاجر:** لا ترفع ملف debug على Uptodown، ولا تغيّر حزمة Android أو توقيع النسخة الحالية. قدّم تحديثًا عامًا فقط بعد خطوة توقيع v1.1.0 وتأكيد التثبيت.

## الاختبارات
- سيناريوهات المتصفح الجديدة تغطي إضافة المهام والتذكيرات باللغة العربية، التراجع عن الحفظ الفاشل، سلامة XP، وضع اليوم الخفيف، راحة العادات، منع روابط العادات الدائرية، خصوصية الاستيراد، وDeep Links المرتبطة بتسجيل الدخول.
- اختبارات الوحدة تشمل فصل بيانات الكتاب الأصلي عن الطبعات العربية الموثقة، والبحث بـISBN.
- اختبارات JavaScript وPlaywright وLighthouse تعمل آليًا بعد كل تحديث على main.
