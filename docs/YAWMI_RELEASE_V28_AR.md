# يومي LifeOS V28 — مراجعة الإغلاق والرتب

تاريخ المراجعة: 2026-11-04.

## الإصلاحات المُطبقة
- تحديث حساب النقاط الموسمية ليشمل كل أيام الموسم، وليس آخر 14 يومًا فقط.
- قبل إغلاق أي موسم، تعيد وظيفة الإغلاق حساب كل أيام الموسم من آخر مستند سحابي محفوظ لكل حساب، ثم تنشئ النتائج والأوسمة مرة واحدة.
- تخزين `peak_xp` والرتبة الأعلى `peak_rank` في الأرشيف دائمًا، حتى عندما تنخفض نقاط نهاية الموسم.
- واجهة الأرشيف تعرض الرتبة النهائية وأعلى رتبة بلغها المستخدم.

## الاختبارات
- SQL transaction ثم Rollback: إغلاق موسم افتراضي واستخراج جوائز 8 حسابات، دون تغيير حسابات المستخدمين.
- SQL transaction ثم Rollback: رصيد نهائي 0 XP مع رقم ذروة 1400 XP -> الرتبة النهائية برونز وأعلى رتبة جولد.
- استدعاء ranked_sync وranked_dashboard بصلاحيات authenticated في معاملة تم التراجع عنها: الموسم S01 والرتبة برونز.
- مراجعة الصلاحيات أظهرت أنه لا يمكن لـ authenticated الكتابة المباشرة في بيانات الترتيب.

## قيود متبقية ينبغي إعلانها
- نتائج نهاية الموسم تحسب آخر حالة **محفوظة على السحابة** قبل الإغلاق؛ التغييرات الأوفلاين التي لم تُرفع قبل انتهاء الموسم لا تدخل الجوائز. يلزم إبلاغ المستخدم بذلك.
- حساب إنجازات التطبيق ذاتي التسجيل، ولا يثبت النشاط خارج التطبيق. توجد حدود للنقاط والطلبات، لكنها ليست منعًا كاملًا للغش.
- المزامنة مع تعارض تعديلين في نفس الحقل ما زالت تتطلب مراجعة صاحب الحساب بدل الكتابة فوق بياناته.
- تدفق PWA والتسجيل والتنقل بين جهازين لم يُختبر باختبار شامل داخل متصفح بحسابين حقيقيين.
- **النشر العام لم يُؤكَّد:** GitHub Pages ظل يعرض 404 للملفات الجديدة أثناء وجود مهام Pages queued. لا ينبغي وصف هذه النسخة بأنها متاحة للمستخدم النهائي قبل تحقق الروابط.
